# NYC Schools APEX

Oracle APEX application built at a hackathon event with high schools from New York City, featuring AI integration.

## About

This application was developed during a collaborative hackathon between Romanian and New York City schools. It manages school applications, student data and parent communication using Oracle APEX and AI-powered features.

## Features

- School application management
- Student and parent data tracking
- AI integration for automated processing
- Reports and dashboards
